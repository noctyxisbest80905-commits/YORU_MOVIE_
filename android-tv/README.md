# Yoru Android TV — created by Obscura

Current Android source: versionCode 4, `0.4-yoru-tv-offline-immersive`. Android 8+; ARM64, ARMv7 and x86_64.

This full cumulative source includes Yoru branding, Obscura/provider/upstream credits, favorites/settings, language and quality selection, history/Continue watching, the always-on explicit-content filter, and offline downloads. Phone playback also adds immersive system-bar hiding and rotation. Fit/Fill and control lock are included in both apps.

See the repository README.md and ANDROID_OFFLINE_FULLSCREEN.md for features, limits, signing and verification. Read safety/README.md for filter limitations. Downloads are private app data; external subtitle URLs, live and protected downloads are not supported. No actual media is bundled.

## Rebuild
Workflow: `.github/workflows/yoru-android-tv.yml`. A visible identical workflow copy is in this folder. GitHub Actions installs the toolchains and compiles the JNI backend from the included source. Local builds require JDK 17, Gradle 8.10.2, Android SDK 35/build-tools 35.0.0, NDK 27.2.12479018, the Rust Android targets and cargo-ndk 4.1.2.

The existing script produces a **debug-signed** APK with a `filtered.apk` filename, but its source version is v0.4. Configure your own stable private release signing for future production distribution. The already-signed, non-debuggable v0.4 APK is included separately in the outer ZIP's installers/ folder; no private signing key is shipped.

Package ID: `com.obscura.yoru.tv`. The supplied v0.4 APK can update the matching filtered v0.3 app in place. Earlier differently signed builds or APKs generated by a fresh GitHub runner may be incompatible for in-place installation. Do not uninstall without understanding that it removes history, favorites, settings and downloads.

42 local JVM tests and browser fixture checks passed. APK signature, version/ID, three ABI libraries, 16-KiB ZIP alignment and current bundled asset bytes were verified. Native playback/downloads and device-specific immersive behavior still require physical-device testing. See VALIDATION.json.
