Streaming providers & servers

Yoru connects to these independent third-party providers. Sources, links, and availability are supplied by them.

  • MovieBoxDiscovery, titles, streams & subtitles
  • 4KHDHubCatalog & release links
  • DramachiCatalog, episodes & streams
  • CircleFTPBDIX provider · compatible network required
  • DhakaFlixBDIX provider · compatible network required

Mirror/CDN hosts vary by release. The 4KHDHub resolver includes HubCloud and Pixeldrain support. Where available, the resolved streaming host is identified after launching playback; no single server is implied for all movies.

Open-source foundation

MovieBox TUI — original terminal application and shared Rust provider engine, by the upstream MovieBox TUI contributors (mesamirh/MovieBox-Tui). Yoru's Android app builds on that work. Original MIT / Apache-2.0 notices are retained.

  • AndroidX Media3 / ExoPlayerBuilt-in playback, audio and subtitle controls · Apache-2.0

  • AndroidX WebKitWebView integration · Apache-2.0

Android player

Built-in playback uses AndroidX Media3 / ExoPlayer and Android System WebView. No separate VLC or mpv app is required. Media3 and AndroidX WebKit are Apache-2.0 projects by their respective contributors.

Offline content-filter data

Derived from manami-project / anime-offline-database. The title-index database is ODbL-1.0 + DbCL-1.0; full licenses, attribution, and the complete derived index are included with the app and source update. No runtime lookup sends your searches to the dataset project.
